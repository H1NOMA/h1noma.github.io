# Резервные копии базы KOMIK

Автоснапшоты таблицы Supabase `kv` (gzip), по одному в день.
Хранятся только последние копии (лимит — 31, около месяца): ветка каждый день пересобирается одним коммитом,
более старые копии удаляются вместе с историей.

Сейчас копий: 31, самая старая — kv-2026-09-03.json.gz.
