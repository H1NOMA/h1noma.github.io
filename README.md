# Резервные копии базы KOMIK (зашифрованные)

Снапшоты таблицы `kv`, по одному в день: `kv-ГГГГ-ММ-ДД.json.gz.gpg` — JSON (массив `{key, value}`),
сжатый gzip и зашифрованный gpg (AES-256) парольной фразой владельца. Без неё файл не прочитать.
Как расшифровать — `migrate/RESTORE.md` (раздел 10) в ветке main.

Хранятся копии за последнюю неделю (7 дней): ветка каждый день пересобирается одним коммитом.
Старые коммиты GitHub может ещё какое-то время отдавать по прямой ссылке — поэтому здесь только
зашифрованные файлы.

Сейчас копий: 3, самая старая — kv-2026-10-29.json.gz.gpg.
