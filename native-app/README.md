# КОМИК · приложение (Expo / React Native)

Мобильное приложение поверх общего ядра `../native-core` (правила, архив, данные).
**Только телефоны и планшеты** (portrait, `supportsTablet`), веб-цели нет.
Веб-версия сайта (`index.html`) не затронута.

> Собрать и запустить нужно на твоей машине (для iOS-сборки — Mac + Xcode; для быстрого
> просмотра хватает телефона с Expo Go). В песочнице сборка не гоняется.

## Что внутри

- **Реальные данные.** Бандл карточек в `assets/data/`: ядро SRD (2850) + бестиарий (2213)
  + встроенный архив сайта. Плюс облако **Supabase — та же база, что у сайта**: архив,
  персонажи, игры, доска и новости синхронизируются с вебом.
- **Новости** — приветствие сеттинга + новости из облака (pull-to-refresh).
- **Архив** — категории/подкатегории своего сеттинга (у ASSIMILATION — свои; закрыт
  не-разработчикам), поиск, полная карточка: досье, статблок-сетка существ, разделы, теги, источник.
- **Игроки** — полный цикл персонажа: список → создание/правка (модификаторы и бонус
  мастерства считает ядро) → полный лист с бросками кубов → удаление (надгробие, синк с сайтом).
- **Игры** — расписание: запись с прикреплением персонажа, отмена; у ГМа — создание и «Игра сыграна».
- **Доска** — стол боя: ГМ ведёт список, публикует и включает для игроков; игрок видит
  активную доску вживую и правит ХП своей карточки.
- **Профиль** — вход по тегу; права как на сайте (разработчики — ГМ).
- **Тема и переключатель сеттинга** — цвета из токенов ядра, совпадают с вебом.

## Запуск

```bash
cd native-app
npm install
npx expo start        # i — iOS-симулятор, a — Android; телефон — Expo Go по QR
```

## Обновление данных из сайта

Карточки бандла пересобираются из `index.html` одной командой:

```bash
node ../native-core/data/extract.mjs
cp ../native-core/data/{core-data,core-bestiary,archive-data}.json assets/data/
```

## Структура

```
native-app/
├─ App.js                  корень: шапка + вкладки + переключатель сеттинга
├─ index.js / app.json / babel.config.js / metro.config.js
├─ assets/data/            реальные карточки (ядро, бестиарий, встроенный архив)
└─ src/
   ├─ theme.js             тема из токенов ядра
   ├─ session.js           сессия (вход по тегу, права)
   ├─ store.js             хранилище: Supabase-облако + AsyncStorage-зеркало
   ├─ asyncLocalStore.js   адаптер AsyncStorage → интерфейс Store
   ├─ data.js              сборка архива сеттинга (бандл + облако + правки ядра)
   ├─ chars.js             персонажи (пер-юзерный облачный ключ сайта)
   └─ screens/             News / Archive / Characters / Schedule / Board / Profile
```
