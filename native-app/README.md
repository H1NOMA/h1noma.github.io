# КОМИК · приложение (каркас Expo)

Каркас мобильного приложения на **Expo / React Native**, работающий поверх общего ядра
`../native-core` (правила, архив, данные). Веб-версия (`index.html`) не затронута.

> Собрать и запустить нужно у тебя на машине (для iOS — Mac + Xcode). В песочнице сборка не гоняется —
> здесь только исходники, готовые к `npm install && npx expo start`.

## Что уже есть

- **Тема из токенов сеттингов** — цвета берутся из `native-core/settings.THEME`, совпадают с вебом.
- **Переключатель сеттинга** в шапке: тап по названию → список, каждый сеттинг своим цветом.
- **Экран «Лист»** — живой лист персонажа: характеристики, спасброски, навыки, лимиты заклинаний
  считаются ядром (`deriveSheet`), плюс демо-бросок кубов (`rollPool`).
- **Экран «Архив»** — живой поиск/фильтр через `queryArchive` (на демо-данных).
- **Слой хранилища** — `store.js`: AsyncStorage-локаль; облако Supabase подключается парой строк.

Данные экранов пока **синтетические** (`src/sampleData.js`) — чтобы каркас запускался без бэкенда.

## Запуск

```bash
cd native-app
npm install
npx expo start        # дальше: i — iOS-симулятор, a — Android, w — web
```

Для устройства — приложение **Expo Go** (сканируешь QR из терминала).

## Подключить настоящие данные

1. **Карточки архива:** `node ../native-core/data/extract.mjs` — сгенерирует `core-data.json` и др.
   Положи нужные в `native-app/assets/data/` и импортни в экран архива вместо `SAMPLE_CARDS`.
2. **Облако (аккаунты/персонажи/расписание/стол):** в `src/store.js` раскомментируй блок Supabase
   и вставь `SUPABASE_URL` / `SUPABASE_ANON_KEY`. Дальше репозитории из `native-core/data`
   (`gamesRepo`, `boardRepo`, `charactersRepo`) заработают против той же базы, что и веб.

## Структура

```
native-app/
├─ App.js                  корень: шапка + вкладки + переключатель сеттинга
├─ index.js                точка входа Expo
├─ app.json               конфиг Expo
├─ metro.config.js        доступ к ../native-core (монорепо watchFolders)
└─ src/
   ├─ theme.js            провайдер темы из токенов ядра
   ├─ store.js            хранилище (локаль + опц. облако)
   ├─ asyncLocalStore.js  адаптер AsyncStorage → интерфейс Store
   ├─ sampleData.js       демо-персонаж и демо-карточки (выдуманные)
   └─ screens/
      ├─ SheetScreen.js   лист персонажа
      └─ ArchiveScreen.js архив (поиск/фильтр)
```
