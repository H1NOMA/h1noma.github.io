# Прототип приложения КОМИК

Это **не часть сайта**. Файл лежит в отдельной папке и в ветку `main` не
мержится, поэтому на komikdnd.ru никак не влияет: GitHub Pages раздаёт `main`.

## Что это

Оболочка мобильного приложения с главной новинкой — **шторкой** в духе
мобильного Claude: полотно уезжает вправо, слегка уменьшается и скругляется,
шторка идёт следом с параллаксом. Жест ведётся пальцем один-в-один, отпускание
решается по скорости, а не только по положению.

Визуальный язык сайта сохранён без изменений: те же пять палитр сеттингов,
матовое стекло, волосяные границы, пружинная кривая `cubic-bezier(.32,.72,0,1)`.
Новое — только навигация.

## Как открыть

Открыть `prototype/app.html` в браузере телефона. Жесты:

- потянуть от левого края — шторка едет за пальцем;
- быстрый флик — открывает или закрывает, не доводя до конца;
- тап по затемнению или Esc — закрыть;
- карточка открывается листом снизу, лист тянется вниз за «ручку».

## Что внутри

- шторка: профиль, поиск, пять миров, разделы, закладки;
- разделы: Новости, Доска ходов, Игроки, Архив, Настройки;
- архив с категориями, поиском и карточками;
- карточка существа/заклинания/класса нижним листом;
- 19 настоящих карточек из архива — данные не выдуманы.

## Чего здесь нет

Прототип показывает оболочку и навигацию, а не переписывает приложение.
Облако, авторизация, листы персонажей, доска Мастера, пуши — остаются в
`index.html` и подключаются к этой оболочке без изменений: разделы и данные
те же самые.
